# HomeBay — Smart Rental Housing Finder

HomeBay is a responsive front-end prototype by team NexNest. It is designed to help students, migrants, job seekers and families compare rental homes when moving to an unfamiliar city.

## Prototype features

- Search by city, locality or property title
- Filter by maximum monthly rent, room type and furnishing
- View rent, deposit, amenities and move-in availability
- Save and unsave favourite listings during the current session
- View property details and prepare a demo enquiry
- Demo report action for outdated or suspicious listings
- Responsive layout for mobile and desktop

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or server are required for this front-end demo. The Google Fonts import is optional; the page uses fallback fonts if unavailable.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

The project proposal mentions possible future use of React, Python Flask or Node.js, Firebase or MySQL, and OpenStreetMap or Google Maps. Those backend/database/map integrations are **not implemented** in this starter prototype.

## Sample data and safety

All property listings, owner labels, prices and availability in this demo are fictional sample data. The prototype does not send enquiries, verify property owners, persist favourites to a database, or transmit listing reports. Do not use sample details to make rental decisions.
